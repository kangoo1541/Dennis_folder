## 1. 터미널은 왜 쓰나요?

**비유: 자판기 버튼 vs 주문서**

- 마우스로 클릭하는 화면(GUI) = 자판기 버튼. 쉽지만 버튼에 있는 메뉴만 고를 수 있음
- 터미널(CLI) = 주문서에 직접 적기. 처음엔 낯설지만 **원하는 걸 정확히, 여러 개를 한 번에** 시킬 수 있음

이미 STM32 에서 CLI 를 직접 만들어 봤죠? 그거랑 똑같은 개념입니다.
`led toggle 0 100` 처럼 **명령어 + 인자** 로 컴퓨터에게 일을 시킵니다.

### 꼭 알아야 할 명령어 10개

| 명령어 | 뜻 | 예시 |
|---|---|---|
| `pwd` | 지금 어디 있지? | `pwd` |
| `ls` | 여기 뭐가 있지? | `ls -al` |
| `cd` | 폴더 이동 | `cd study` , `cd ..` (위로) |
| `mkdir` | 폴더 만들기 | `mkdir homework` |
| `touch` | 빈 파일 만들기 | `touch note.md` |
| `cat` | 파일 내용 보기 | `cat README.md` |
| `cp` | 복사 | `cp a.c b.c` |
| `mv` | 이동 / 이름 바꾸기 | `mv old.c new.c` |
| `rm` | 삭제 (휴지통 없음! 주의) | `rm temp.txt` |
| `grep` | 파일 안에서 글자 찾기 | `grep -rn "uartInit" src/` |

> 💡 맥(Mac)은 기본 앱인 **터미널** 에서 위 명령어를 그대로 쓸 수 있습니다.
> Windows 라면 **Git Bash** 라는 프로그램을 설치하면 똑같이 쓸 수 있습니다.

## 2. Git 은 무엇인가요?

**비유: 게임의 세이브(저장)**

게임을 하다가 보스전 전에 저장해 두면, 져도 그 지점부터 다시 할 수 있죠.
세이브 파일이 여러 개면 "어제 저장한 곳"으로도 돌아갈 수 있습니다.

Git 은 **코드의 세이브 기록을 관리하는 도구**입니다. 언제든 예전 저장 지점으로 돌아갈 수 있습니다.

```
  작업 폴더          스테이징            로컬 저장소          GitHub (원격)
  (게임 중)       (저장할 것 고르기)    (내 PC 에 저장)     (클라우드 저장)
     │                  │                   │                    │
     │── git add ──────▶│                   │                    │
     │                  │── git commit ────▶│                    │
     │                  │                   │── git push ───────▶│
     │◀──────────────────────────────────────── git pull ────────│
```

| 단계 | 명령어 | 게임으로 비유하면 |
|---|---|---|
| 수정 | (에디터로 편집) | 게임 진행 |
| 담기 | `git add 파일` | 저장할 항목 고르기 |
| 기록 | `git commit -m "메시지"` | 세이브 슬롯에 이름 붙여 저장 (내 PC) |
| 공유 | `git push` | 세이브를 클라우드에 업로드 |
| 받기 | `git pull` | 다른 기기에서 올린 세이브 내려받기 |

### 상태 확인 명령어 (가장 많이 쓰게 됩니다)

```bash
git status          # 지금 뭐가 바뀌었지?
git diff            # 어디가 어떻게 바뀌었지?
git log --oneline   # 개정 이력 목록
```

## 4. 따라 하기 실습 (직접 타이핑하세요)

### 4-0. 어디서 하나요? (처음 한 번만 준비)

실습은 **내 컴퓨터의 터미널**에서 합니다. GitHub 웹사이트가 아닙니다.
게임으로 치면 "세이브 파일을 내 PC 로 내려받아서, 내 PC 에서 게임하는" 단계입니다.

**① 어떤 컴퓨터에서?**

| 선택지 | 추천 | 설명 |
|---|---|---|
| 개인 맥북 | ⭐ 추천 | 터미널이 이미 들어 있음. Git 만 설치하면 끝 |
| 개인 PC (Windows) | 가능 | Git Bash 설치 필요 |
| 회사 PC | ✕ | 보안 정책상 설치나 GitHub 접속이 막혀 있을 수 있음 |
| 설치가 안 될 때 | 대안 | GitHub Codespaces (브라우저 안의 터미널, 설치 불필요) |

**② 터미널 열기와 Git 설치**

맥북 (추천)

1. `Command(⌘) + Space` 를 눌러 Spotlight 검색창을 엽니다.
2. `터미널` 또는 `Terminal` 을 입력하고 Enter 를 누릅니다. 글자를 입력할 수 있는 창이 뜨면 그게 터미널입니다.
3. 아래 설치 확인 명령을 입력합니다. Git 이 없으면 **"명령어 라인 개발자 도구를 설치하겠습니까?"** 창이 자동으로 뜹니다. **설치** 를 누르고 몇 분 기다리면 됩니다.

Windows

1. https://git-scm.com 에서 **Download for Windows** 를 받아 설치합니다. 옵션은 전부 기본값으로 "Next" 만 누르면 됩니다.
2. 시작 메뉴에서 **Git Bash** 를 엽니다. 이 창이 Windows 용 터미널입니다.

설치 확인 (맥, Windows 공통):

```bash
git --version
```

`git version 2.xx.x` 처럼 나오면 성공입니다.

**③ 내 이름표 붙이기 (처음 한 번만)**

세이브할 때마다 "누가 저장했는지" 가 같이 기록됩니다. 그 이름과 이메일을 등록합니다.
이메일은 GitHub 가입할 때 쓴 것을 적습니다.

```bash
git config --global user.name "내이름"
git config --global user.email "GitHub가입이메일@example.com"
```

**④ 저장소를 내 PC 로 내려받기 (clone)**

공부 자료는 `claude/epic-noether-qwtzyk` 브랜치에 있습니다.
그냥 내려받으면 다른 브랜치가 열려서 `study` 폴더가 안 보이므로, `-b` 로 브랜치를 꼭 지정합니다.

### 4-1. 실습 시작

준비가 끝났으면 아래를 **한 줄씩** 직접 타이핑합니다.

```bash
# 1) 저장소 폴더로 이동
cd ~/Dennis_folder

# 2) 클라우드의 최신 세이브 받기 + 지금 상태 확인
git pull
git status
git log --oneline

# 3) 과제 폴더 만들기
mkdir -p study/homework/W01
cd study/homework/W01

# 4) 파일 만들고 내용 쓰기
echo "# W01 실습 기록" > practice.md
echo "- 오늘 처음으로 터미널에서 파일을 만들었다" >> practice.md
cat practice.md

# 5) Git 에 기록하기
git status                 # 빨간색 = 아직 안 담긴 파일
git add practice.md
git status                 # 초록색 = 담긴 파일
git commit -m "W01 실습: 터미널로 첫 파일 만들기"
git log --oneline          # 내 커밋이 맨 위에 보이면 성공!

# 6) GitHub 에 올리기
git push
```
